# WealthDock roadmap

The roadmap is directional. Privacy, data portability and correctness take
priority over feature count.

## Next

- QIF and OFX importers with duplicate detection.
- Exchange-rate snapshots with an explicit opt-in network adapter.
- Recurring-rule preview calendar and reconciliation workflow.
- Accessibility audit against WCAG 2.2 AA.
- Signed desktop wrappers after the PWA reaches stable usage.

## Later

- End-to-end encrypted sync adapters that never receive a cleartext vault.
- Shared household vaults using client-side key exchange.
- Plugin API for importers and report templates.
- Translation infrastructure and right-to-left layout support.

## Non-goals

- Selling transaction data.
- Mandatory accounts or hosted analytics.
- Storing bank credentials.
- Silent automated transfers or financial advice.
